# Simple Interest Calculator

This project contains a Bash script, `simple-interest.sh`, that calculates simple interest based on user input.

## How it works

The script asks the user for three values:

- **Principal**: the initial amount of money
- **Rate of interest**: the annual interest rate (in %)
- **Time period**: the duration in years

It then calculates the simple interest using the formula:

    Simple Interest = (Principal x Rate x Time) / 100

## Usage

    chmod +x simple-interest.sh
    ./simple-interest.sh
